# ViaRList

#ENG 🇺🇸 🇬🇧
ViaRList is a list of VTubers that is less bureaucratic than the others, ViaRList makes it easier to become part of the list. The data is updated manually, there are no automations.
You can review the code of this project, in the repository corresponding to ViaRList.

This is a non-profit project, or data collection for sale. The data corresponds to your VTuber character, not personal, it is a support for you and nothing more. The purpose is support between content creators.

#ESP 🇲🇽 🇪🇸
ViaRList es una lista de VTubers menos burocrática que las demás, ViaRList hace que sea más fácil formar parte de la lista. Los datos se actualizan manualmente, no hay automatizaciones.
puedes revisar el código de este proyecto, en el repositorio corespondiente a ViaRList.

Este es un proyecto sin ánimos de lucro, o de recolección de datos para su venta. Los datos son correspondientes a tu personaje VTuber, no personales, es un apoyo para ti y nada más. La finalidad es el apoyo entre creadores de contenido.

#JAP 🇯🇵 🇯🇵
ViaRList は他の VTuber よりも官僚的ではない VTuber のリストであり、ViaRList を使用するとリストに参加しやすくなります。データは手動で更新され、自動化はありません。
このプロジェクトのコードは、ViaRList に対応するリポジトリで確認できます。

これは非営利プロジェクト、または販売のためのデータ収集です。データはあなたの VTuber キャラクターに対応するものであり、個人的なものではなく、あなたをサポートするものであり、それ以上のものではありません。コンテンツクリエイター間のサポートを目的としています。


# Request to Join/Solicitar Unirse/参加のリクエスト

#ENG 🇺🇸 🇬🇧
Write to ViaRCreator on X/Twitter sending the following information:
VTuber name, VTuber type (2D, 3D, 3D VR), your country of origin, a very brief description of what you do, indicate whether your avatar is your own or you use a public one (in the case of VRChat), three social network links maximum, date of your first published content.
For the profile photo, you must publish the file in a normally supported format, on the "https://catbox.moe/" website, and send the link provided by the website, along with the data requested above.
As the sole maintainer of the site, it may take a few days for the profile to be published. Thank you for your understanding.

#ESP 🇲🇽 🇪🇸
Escribe a ViaRCreator en X/Twitter enviando los siguientes datos:
Nombre de VTuber, tipo de VTuber(2D, 3D, 3D VR) tu país de origen, una muy breve descripción de lo que haces, indica si tu avatar es propio o usas uno público(en caso de VRChat), tres enlaces de redes sociales como máximo, fecha de tu primer contenido publicado.
Para la foto de perfil, debes publicar el archivo en un formato normalmente admitido, en la web "https://catbox.moe/", y enviar el enlace que entrega la web, junto con los datos solicitados anteriormente.
Como único maintainer del sitio, la publicación del perfil podría tardar unos días. Gracias por su comprensión.

#JAP 🇯🇵 🇯🇵
X/Twitter の ViaRCreator に書き込み、次の情報を送信します。
VTuber 名、VTuber の種類 (2D、3D、3D VR)、出身国、あなたの活動の簡単な説明、アバターが自分のものであるか、公開されているもの (VRChat の場合) を使用しているかを示し、最大 3 つのソーシャル ネットワーク リンク、最初に公開されたコンテンツの日付。
プロフィール写真の場合は、通常サポートされている形式でファイルを Web サイト「"https://catbox.moe/"」に公開し、Web サイトが提供するリンクを上記で要求されたデータとともに送信する必要があります。
サイトの唯一の管理者であるため、プロフィールが公開されるまでに数日かかる場合があります。ご理解のほどよろしくお願いいたします。
